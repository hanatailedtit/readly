# Readly 로고

제공된 이미지의 검정 책갈피와 소문자 `readly` 조합을 바탕으로, 심볼·글자의 비율과 간격을 정리한 로고입니다.

| 파일 | 용도 | 크기 |
| --- | --- | --- |
| `readly-logo.svg` | 기본 검정 로고 | 216×72, 벡터 |
| `readly-logo-white.svg` | 어두운 배경용 흰색 로고 | 216×72, 벡터 |
| `readly-symbol.svg` | 책갈피 단독 심볼 | 64×64, 벡터 |
| `readly-symbol-white.svg` | 흰색 단독 심볼 | 64×64, 벡터 |
| 같은 이름의 `.png` | 투명 배경 이미지 | 로고 1296×432 / 심볼 512×512 |
| `preview.png`, `preview.svg` | 기본형·반전형·작은 크기 사용 예 | 1200×860 |

로고의 SVG는 텍스트와 외부 이미지 없이 모두 벡터 윤곽선으로 구성했습니다. 폰트 설치 없이 Figma·Illustrator·웹에서 같은 모양으로 사용할 수 있습니다. 미리보기 보드의 설명 문구는 로고와 별개입니다.

- 기본 색상은 `#141414`, 반전 색상은 `#FFFFFF`입니다.
- 모든 로고·심볼 PNG는 투명 배경입니다. 흰색 버전은 어두운 배경에서 확인하세요.
- 비율을 유지해 확대·축소합니다. 가로형은 폭 108px 이상, 심볼은 24px 이상을 권장합니다.
- Figma에는 ZIP의 압축을 풀고 SVG를 드래그합니다.
- 워드마크는 Pretendard Bold를 바탕으로 윤곽선으로 변환했습니다. 원본 글꼴의 OFL 라이선스를 동봉했습니다.

SVG와 PNG의 크기·윤곽선·투명 여백을 검사하고, 밝은 배경·어두운 배경·축소 크기로 시각 확인했습니다. 기존 앱과 화면 시안은 이 작업에서 수정하지 않았습니다.
