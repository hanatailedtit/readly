# Readly 디자인 v1

기존 와이어프레임의 8개 페이지에 디자인을 입힌 별도 시안입니다. 데스크톱 1440px와 모바일 390px, 대체 상태를 포함해 총 34개 SVG·PNG를 제공합니다. 실제 앱 코드는 변경하지 않았습니다.

## 열어보기

`index.html`을 열면 서버나 네트워크 없이 볼 수 있습니다.

- 상단의 페이지·기기 선택기로 8개 화면과 데스크톱·모바일을 전환합니다.
- 메인·기록 목록·도서 상세에서 리스트·그리드를 바꾸고, 최신순·인기순·댓글순을 확인합니다.
- 모바일 도서 목록은 한 줄에 한 권입니다. ‘기록이 달린 도서만 보기’를 켜면 8권에서 6권으로 줄어듭니다.
- 도서 → 도서 상세 → 기록 상세로 이동합니다. 댓글·대댓글과 답글 입력 상태가 포함되어 있습니다.
- 기록 남기기 → 도서 검색 → 선택 → 책 변경 흐름을 확인합니다. ‘책 전체’를 켜면 쪽수 입력창을 유지하며 비활성화합니다.
- 상단 상태 버튼과 로그인·가입·등록 버튼으로 오류 상태를 확인합니다.
- 현재 화면의 SVG를 직접 저장할 수 있습니다.

화면의 기록·댓글·집계·서지 정보는 검토용 예시입니다. 표지는 이 시안용으로 제작한 벡터 일러스트이며 실제 출판 표지가 아닙니다. 검색·인증·저장·좋아요는 실제 API와 연결하지 않은 인터랙션 시안입니다. SVG 기반 화면이라 입력창에 실제 본문을 입력하는 편집기는 구현하지 않았습니다.

## Figma로 가져오기

1. `readly-design-figma-import.zip` 또는 모바일 전용 ZIP의 압축을 풉니다.
2. 텍스트 편집이 필요하면 `fonts`의 Pretendard와 Gowun Batang 글꼴을 설치합니다.
3. SVG 파일을 Figma Design 캔버스에 드래그합니다. ZIP 자체를 업로드하는 방식은 아닙니다.

SVG는 벡터와 텍스트를 담습니다. Figma 네이티브 컴포넌트·오토레이아웃·프로토타입 연결은 자동 생성되지 않습니다. 인터랙션 흐름은 `index.html`에서 확인합니다.

## 디자인 기준

`use-design-md`와 `frontend-design`을 사용했습니다. [ko-design-md의 리디 항목](https://www.getdesign.kr/services/ridi/llms.txt)을 2026-10-23에 읽고 흰 바탕, 무채색 면, 작은 모서리, 제한된 파랑, Pretendard UI를 참고했습니다. 카탈로그의 [출처·라이선스](https://github.com/CaesiumY/ko-design-md)는 원본 저장소에서 확인할 수 있습니다. 서비스·로고·브랜드 자산은 가져오지 않았습니다.

고운바탕 제목, 책갈피 형태, 펼친 책 히어로, 시안 표지, 모바일 한 열 배치, 짙은 주요 버튼은 Readly를 위해 확장·조정한 부분입니다. 원본의 밝은 파랑 버튼은 흰 글자와 대비가 부족해 blue-700으로 대체했습니다. 값별 근거와 차이는 `DESIGN.md`에 기록했습니다.

모든 페이지의 헤더·푸터에는 승인한 책갈피·소문자 워드마크 로고를 적용했습니다. 로고는 `assets/readly-logo.svg`와 동일한 윤곽선을 SVG 안에 직접 포함해 폰트나 외부 이미지 없이 표시됩니다. 미리보기 도구 막대에는 흰색 반전형을 사용합니다.

Pretendard와 Gowun Batang은 각각 동봉된 OFL 라이선스를 따릅니다. 수정하지 않은 글꼴 파일이며 시스템에 자동 설치하지 않습니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 페이지·기기·상태 전환이 가능한 로컬 미리보기 |
| `screens/` | 데스크톱 17개 + 모바일 17개 SVG |
| `previews/` | 같은 화면의 PNG |
| `overview.png` | 데스크톱 기본 8화면 개요 |
| `mobile-overview.png` | 모바일 기본 8화면 개요 |
| `screens.json` | 화면 파일명·상태·크기 목록 |
| `DESIGN.md` | 참고 문서·토큰·Readly 확장 사항 |
| `design.js` | 공통 컴포넌트·화면 생성 원본·SVG 렌더러 |
| `build.cjs`, `verify.cjs` | 재생성 및 검사 스크립트 |

## 재생성·검사

검사는 Node.js 기본 기능만 사용합니다. PNG 생성에는 `@resvg/resvg-js`가 필요합니다. 앱의 의존성을 변경하지 않도록 별도 경로에 설치할 수 있습니다.

```bash
node design/readly-design-v1/verify.cjs
npm install --prefix /tmp/readly-design-tools @resvg/resvg-js
NODE_PATH=/tmp/readly-design-tools/node_modules node design/readly-design-v1/build.cjs
```

34개 출력 상태와 320·375·390·414px의 페이지·상태 조합, 총 322개 장면의 경계를 검사했습니다. 표지 비율·카드 정렬·필터 개수·쪽수 입력 비활성화·댓글·텍스트 대비와 실제 미리보기 이벤트 핸들러도 검사했습니다. 기본 16화면 및 주요 오류·스위치 상태는 PNG로 시각 검수했습니다. 브라우저 자동화·실제 API 연동 검증은 수행하지 않았습니다.
