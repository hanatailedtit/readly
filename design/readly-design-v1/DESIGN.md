# Readly · 읽고 남은 마음

책을 읽고 난 뒤의 생각을 기록하고, 같은 책을 읽은 사람들의 시선을 만나는 서비스다. 기존 8개 화면, 데스크톱·모바일 34개 상태와 탐색 흐름을 유지한다.

## 참고 문서와 적용 범위

- 기준: [ko-design-md의 리디 항목](https://www.getdesign.kr/services/ridi/llms.txt), 2026-10-23 조회. 공개 자료를 정리한 커뮤니티 카탈로그이며 공식 디자인 시스템 자체는 아니다.
- 가져온 규칙: 흰 바탕과 무채색 면, 4px 카드·표지 모서리, 6px 주요 버튼, 8px 입력창, 20px 히어로, Pretendard UI, 얇은 경계선, 그림자 없는 카드, 선택과 행동에 제한한 파랑.
- Known Gaps 반영: 원본 모바일 상세의 잘림은 답습하지 않는다. 모바일은 기존 한 열 구성을 유지한다. 로고·이미지·브랜드 명칭을 가져오지 않는다. 원본에 없는 키보드 포커스·움직임 줄이기 대응을 보완한다. 다크 테마는 이번 시안에 포함하지 않는다.
- 원본의 밝은 파랑과 흰 글자는 대비가 부족하므로 CTA는 같은 문서의 blue-700으로 짙게 조정했다. 이는 Readly의 접근성 보완이며 원본 버튼 사양과 구별한다.

## 색상

| 역할 | 값 | 근거 |
| --- | --- | --- |
| canvas | #FFFFFF | neutral-white |
| ink | #141414 | neutral-900 |
| muted | #636C73 | coolgray-500, 작은 보조 글자의 대비를 위한 선택 |
| surface | #F8F9FA | coolgray-25 |
| border | #E6E8EB | coolgray-100 |
| accent | #1E9EFF | emotion-blue, 현재 위치·선택 표시 |
| action | #1670B5 | blue-700, 흰 글자와 4.5:1 이상 대비 |

추가 상태색은 카탈로그의 red-600, disabled는 neutral-50. 표지의 색상은 UI 강조색이 아닌 콘텐츠 일러스트에만 사용한다. SVG 렌더러 호환을 위해 문서에 병기된 sRGB HEX를 사용하며 OKLCH와 색역·반올림 차이가 있을 수 있다.

## Readly에서 새로 설계한 부분

- 서체: Pretendard는 탐색·입력·목록, 고운바탕 Bold는 첫 소개 문장·본문 제목·독자의 생각에만 사용한다. 고운바탕은 원본의 서체가 아닌 Readly 확장이다. 두 글꼴 모두 OFL 라이선스를 동봉한다.
- 특징: 펼친 책에서 문장 하나를 끌어올린 듯한 히어로와, 기록 카드의 작은 책갈피 모양. 별도 장식 아이콘을 반복하지 않는다.
- 로고: 승인된 `readly-logo`의 책갈피·소문자 워드마크를 모든 화면의 헤더·푸터에 적용한다. 윤곽선 벡터를 포함하고 216:72 원본 비율을 유지하며, 표시 폭은 최대 120px·높이 44px 영역 안에서 맞춘다. 모바일에서 공간이 줄면 같은 비율로 축소한다. 검토 도구 막대는 흰색 반전형을 사용한다.
- 표지: 실제 출판 표지를 복제하지 않고 각 책을 구별할 수 있는 벡터 시안 표지를 제작한다. 공식 표지로 오인하지 않도록 문서에 명시한다.
- 배치: 데스크톱 1440px / 콘텐츠 1200px, 모바일 390px / 여백 16px는 기존 와이어프레임을 유지한 값이며 원본의 컨테이너 사양과 다르다.
- 모바일 도서 목록은 한 줄에 한 권, 표지 88×132px. 연결 도서 80×120px, 기록 목록 72×108px. 표지 비율 2:3 유지.
- 본문을 읽는 페이지는 장식보다 행간과 문장 폭을 우선한다. 로그인·가입에도 같은 제목·입력·오류·버튼 규칙을 적용한다.

## 디자인 선택 검토

초기 후보인 크림색 전체 바탕·장식용 큰 따옴표는 독서 서비스에 흔한 표현이어서 제외했다. 차가운 흰색 위에 책 표지와 실제 기록 내용이 개성을 만드는 방향으로 정리했다. 구매·대여·독점 등 참고 서비스의 도메인 개념은 도입하지 않는다.

## 검증과 한계

모든 SVG를 PNG로 렌더링해 화면별 시각 검수를 진행한다. 목록·필터·댓글·검색·쪽수 스위치·오류 상태와 모바일 320·375·390·414px 컨테이너 경계를 검사한다. 모든 기록·댓글·집계는 화면 검토용 예시이며 실제 인증·저장·조회 API와 연결하지 않는다. 실제 앱 코드는 변경하지 않는다.
