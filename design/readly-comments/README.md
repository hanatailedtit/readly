# 댓글 입력창 개선

- 기존 Readly 디자인 문서(`design/readly-design-v1/DESIGN.md`)를 따르는 부분 확장이다.
- `use-design-md`의 리디 카탈로그를 2026-10-29 다시 확인했다. 흰 바탕, 차가운 회색 면, 얇은 경계, 그림자 없는 구성과 기존 접근성 보완 CTA 색을 유지한다.
- 색상은 기존 `background`, `foreground`, `muted`, `muted-foreground`, `border`, `primary` 토큰을 재사용한다. 전역 팔레트를 변경하지 않는다.
- Pretendard의 입력 본문 16px, 작성자 14px, 안내 12px로 위계를 나눈다. 고운바탕은 기존 독서 본문·제목에 남겨두고 입력 UI에는 추가하지 않는다.
- 아바타·작성자 / 테두리 없는 입력 영역 / 구분선과 안내·등록 버튼을 하나의 8px 프레임으로 묶는다. 모바일에서는 하단 안내와 버튼을 두 줄로 배치한다.
- 댓글과 답글은 같은 `CommentComposer`를 사용한다. 답글에는 받는 사람과 취소 버튼을 표시한다.
- 카탈로그는 댓글 입력 컴포넌트를 규정하지 않는다. 이 입력창의 배치·상태와 포커스 처리는 Readly를 위한 확장 설계다. 원본의 모바일 잘림과 밝은 파랑·흰 글자의 낮은 대비를 답습하지 않는다.
- shadcn/ui의 Avatar·Textarea·Label·Button을 재사용하며 스타일은 Tailwind CSS로 구성한다.

검수 PNG는 로컬 목업 API 응답으로 확인한 화면이다. 운영 서비스의 사용자 데이터나 실제 등록 결과를 나타내지 않는다.

## 확인 결과

- 타입 검사와 린트 통과, 기존 테스트 27개 통과.
- 로컬 페이지에서 320·375·390·768·1440px 너비의 가로 넘침과 입력창 크기 확인.
- 빈 값·공백의 등록 비활성, 키보드 버튼 포커스, 등록 중 비활성·로딩 표시 확인.
- 댓글·답글 요청 형식과 저장 성공 후 초기화, 취소·실패 후 입력 유지 확인.
- 비로그인 입력 비활성과 현재 기록으로 복귀하는 로그인 링크 확인.
- 테스트의 모든 API 조회·저장은 격리된 목업으로 처리함.
